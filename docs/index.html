What it does

A demo-ready story from the road to revenue: see the traffic, see the money, and see Dynatrace find the problem.

🛣️

Animated gantry

2 directions × 4 lanes. Laser sweeps, tag pulses and camera flashes at the gantry; a colored halo and badge show tag, OCR, review or unread.

Every vehicle is one simulated transaction · day/night, fog, IR cones
📈

Live KPI ribbon

Plaza health, transactions and revenue today, flow vs expected, automatic identification, OCR confidence, passage-to-charge p95.

Green / yellow / red thresholds · loss metrics are never green · rolling counters · sparklines
📷

OCR camera view

The last plate decoded character by character with per-character confidence; the image blurs in fog and goes dark when the IR illuminator fails.

Fictitious plates, masked by default (last two digits)
💸

Road to revenue

One dot per transaction through edge services, queue tanks, rating, tag gateway and partners; coins fly to the revenue KPI when charges settle.

Circuit breaker, dead-letter queue and reprocessing burst · zoom into a large live view

Collapsible drawer with root cause, affected entities, live impact, time to detection, recommended action and a streamed explanation.

Scripted and labelled "Simulation" · Strato AI chip and disclaimer

Under the hood

How it works

The important behaviors to understand before running it in a real environment.

🔵 Everything is simulated

No data leaves or enters the tenant. The operator, gantry, tag issuers, partners, plates and incidents are fictitious; Intelligence texts are scripted per scenario.

🟡 Incidents run in accelerated replay

Rates come from the live vehicles; accumulated values (backlog, revenue at risk, duration) follow a scripted timeline at about 100×. The header says so whenever it is active.

🟢 Local time zone

Volume, day/night and headlights follow the viewer's clock. Use the presenter's simulated hour for a peak at any time of day.

🟣 Deterministic by seed

The same seed replays the same sequence of vehicles, so a demo can be rehearsed.

🔵 Hidden tabs

When the tab is hidden only the daily totals advance; vehicles resume when you return.

🟢 Preferences are per browser

Masking, pinned camera, TV mode and the optional dashboard ID live in localStorage.

A future real-data mode would poll Business Events — polling is the dominant cost driver. No such query ships yet, so there is no measured figure to publish: measure scannedBytes for your own query first, then GB/month ≈ GB_per_query × queries_per_hour × hours_per_day × days × concurrent_tabs. * Multiply GB scanned by your DPS "Grail Query – data analyzed" rate — the amount depends entirely on your rate card.

Measure it precisely

  • Run the query in a Notebook and read metadata.grail.scannedBytes from queryExecute.
  • Confirm aggregates in Account Management → Cost & usage → Grail Query.

Reduce it (future real-data mode)

  • Poll at the slowest interval the demo tolerates; pause when the tab is hidden.
  • Keep the window narrow and read only new records since the last poll.
  • Project only needed fields with | fields … (Grail is columnar).
  • Pre-aggregate KPIs instead of re-reading raw events.

Get running

Install it in your environment

From zero to the app running for every user of your tenant, in about five minutes.

  1. Check your permissions. Your user needs app-engine:apps:install and app-engine:apps:run in the target environment (ask your Dynatrace admin if not). You also need Node.js 24 and npm ≥ 9.
  2. Get the code. 
    git clone https://github.com/adrianorafael/multi-lane-free-flow.git
cd multi-lane-free-flow
npm install
  3. Point it at your environment. In app.config.json, replace YOUR-ENVIRONMENT in environmentUrl with your tenant ID — copy it from your browser's address bar: https://YOUR-TENANT-ID.apps.dynatrace.com/.
  4. (Optional) Try it first without installing: npx dt-app dev, then open the local-dev-server link it prints (not localhost:3000 directly).
  5. Install it. 
    npx dt-app deploy
    The first run opens your browser for the Dynatrace login. The app declares no OAuth scopes, so there is no data-access consent screen.
  6. Open it in Dynatrace: Apps (or search) → Multi-lane Free Flow.
  7. Present it: P opens the presenter panel, 1–6 trigger the scenarios, I opens Dynatrace Intelligence — or start the 5-minute automatic tour from the presenter panel.
  8. Update or remove it: bump app.version and run npx dt-app deploy again; npx dt-app uninstall removes it (needs app-engine:apps:delete).

npm scripts

  • npm run start — dev server
  • npm run build — production build
  • npm run deploy — deploy to your env
  • npm run lint · typecheck · test:sim · scan:secrets

Required OAuth scopes

  • None. The app runs entirely in the browser on simulated data.
  • Adding a scope later would be a MAJOR version: every user re-consents.
Help

Troubleshooting

SymptomCause & fix
'app.description' must NOT have more than 80 characters Shorten the description in app.config.json.
Deploy fails because the version already exists Bump app.version in app.config.json (and CHANGELOG, README, page).
The app opens at localhost:3000 but looks broken Open the link printed by npx dt-app dev — the app must run inside Dynatrace.
Few vehicles on screen It is night or early morning in your time zone: use the presenter panel's 6 pm simulated hour or the holiday exodus scenario.
Nothing moves The simulation is paused (Space) or the browser tab was hidden; press Space.
Animations feel heavy on a slow laptop Use 1× speed, avoid combining several scenarios, or enable the OS "reduce motion" setting.
"Open dashboard" button missing Paste a dashboard document ID into the presenter panel; the button only shows when set.
Warning about the Node.js version dt-app supports Node 24; newer versions work but print a warning.
